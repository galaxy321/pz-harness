[h1]Test Ground Bridge (for scripts and AI agents)[/h1]

An add-on for [b]Test Ground[/b] that lets a script or an AI coding agent drive it from outside the game, so it can build and run test cases for your own mods while you watch.

[h2][b]Read this first: security[/b][/h2]
Once a second the bridge reads [i]Zomboid\Lua\TestGround_cmd.txt[/i] and runs each line. One command, [i]lua[/i], runs any Lua code. It is [b]off by default[/b]: it works only when the game is started with -debug or the save's sandbox option [b]Test Ground Bridge: allow lua lines[/b] is on. With it on, [b]any program on your PC that can write that file can run code in your game[/b]. Every lua line, run or refused, is logged to [i]Zomboid\Lua\TestGround_bridge_lua.txt[/i].
[list]
[*]Turn the sandbox option on only in a test save, on your own machine, and only while you need it. The other commands work without it.
[*]Don't enable it on a server. It does nothing in multiplayer.
[/list]

[h2]Commands[/h2]
[list]
[*][b]status[/b]: idle or running, position, fps, last report
[*][b]baseline[/b]: run the standard West Point test route
[*][b]survey[/b] [radius] [run]: scan the area for walls, doors, ladders, streets and containers, and write a plan
[*][b]run[/b] [file]: run a plan file from Zomboid\Lua\
[*][b]stop[/b]: stop and write the report so far
[*][b]lua[/b] <code>: run one line of Lua (only with -debug or the sandbox option)
[/list]
Replies are appended to [i]Zomboid\Lua\TestGround_out.txt[/i], and [i]=== done <report>[/i] marks the end of a run.

[h2]Using it with an AI agent[/h2]
The mod folder has an [i]agent-skill\pz-test-ground[/i] folder: a Claude skill that explains the bridge, the plan format, how to add a test step to your own mod and the Build 42 Lua traps found while building Test Ground. Copy that folder into your agent's skills folder (for Claude Code: [i].claude\skills\[/i] in your project, or [i]~\.claude\skills\[/i]). The [i]tools[/i] folder has [i]compare.py[/i], which compares two reports.

You'll find the files under [i]Steam\steamapps\workshop\content\108600\<this item's id>\mods\TestGroundBridge\[/i] once you've subscribed.

[h2]Hands-free runs: auto-queue (not in this item)[/h2]
Queuing runs without sitting at the PC needs a small PowerShell script. It is not shipped in this mod, because the Workshop doesn't take scripts and you should read one before you run it. It lives in the Test Ground project's GitHub repository, with setup instructions:
[url=https://github.com/galaxy321/pz-harness]https://github.com/galaxy321/pz-harness[/url]
It starts the game with a run queued, waits for the finished report and quits. Use it only on a test copy of a save.
