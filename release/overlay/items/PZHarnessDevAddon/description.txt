[h1]PZ Harness Dev Add-on (for scripts and AI agents)[/h1]

An add-on for [b]PZ Harness[/b] that lets a script or an AI coding agent drive it from outside the game, so it can build and run test cases for your own mods while you watch. [b]Update both items together:[/b] the add-on needs the same version of PZ Harness.

[h2]What is in this item[/h2]
[list]
[*][b]PZ Harness: Bridge (dev add-on)[/b]: the command-file bridge, with a Claude skill, guides and a report comparison tool.
[*][b]PZ Harness: UI check and tour (dev add-on)[/b]: measures PZ Harness's own screens for layout defects and can walk through them taking screenshots. Does nothing unless a flag file asks for it.
[/list]

[h2][b]Read this first: security[/b][/h2]
Once a second the bridge reads [i]Zomboid\Lua\TestGround_cmd.txt[/i] and runs each line. One command, [i]lua[/i], runs any Lua code. It is [b]off by default[/b]: it works only when the game is started with -debug or the save's sandbox option [b]Test Ground Bridge: allow lua lines[/b] is on. With it on, [b]any program on your PC that can write that file can run code in your game[/b]. Every lua line, run or refused, is logged to [i]Zomboid\Lua\TestGround_bridge_lua.txt[/i].
[list]
[*]Turn the sandbox option on only in a test save, on your own machine, and only while you need it. The other commands work without it.
[*]Don't enable it on a server. It does nothing in multiplayer.
[/list]

[h2]Commands[/h2]
[list]
[*][b]status[/b]: idle or running, position, fps, last report
[*][b]baseline[/b] [quick]: run the standard West Point test route (or the 5-minute quick one)
[*][b]survey[/b] [radius] [run]: scan the area for walls, doors, ladders, streets and containers, and write a plan
[*][b]run[/b] [file]: run a plan file from Zomboid\Lua\
[*][b]stop[/b]: stop and write the report so far
[*][b]lua[/b] <code>: run one line of Lua (only with -debug or the sandbox option)
[/list]
Replies are appended to [i]Zomboid\Lua\TestGround_out.txt[/i], and [i]=== done <report>[/i] marks the end of a run.

[h2]Using it with an AI agent[/h2]
In the Bridge mod's folder, [i]agent-skill\[/i] holds Claude skills: how to drive PZ Harness through the bridge, how to write and patch a Build 42 mod, and how to find and fix a slow mod. Copy a skill folder into your agent's skills folder (for Claude Code: [i].claude\skills\[/i] in your project, or [i]~\.claude\skills\[/i]). [i]guides\[/i] explains how to build your own bridge, capture tool and autopilot, so you can reproduce them without installing anything. [i]tools\compare.py[/i] compares two reports.
You'll find the files under [i]Steam\steamapps\workshop\content\108600\<this item's id>\mods\TestGroundBridge\[/i] once you've subscribed.

[h2]Hands-free runs and auto-queue[/h2]
The flag-file engine is part of PZ Harness (see its page). A PowerShell auto-queue script for queuing runs lives in the project's GitHub repository, with setup instructions. It is not part of this item, because the Workshop doesn't take scripts and you should read one before you run it:
[url=https://github.com/galaxy321/pz-harness]https://github.com/galaxy321/pz-harness[/url]
Use it only on a test copy of a save.
