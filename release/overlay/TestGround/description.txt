[h1]Test Ground (Build 42 performance test bench)[/h1]

Measure how a mod setup plays, the same way every time. Test Ground drives, walks and fights through one fixed scripted route and writes the frame times of each part to a report, so you can compare two mod lists, a patch on and off, or a settings change, without replaying anything by hand.

[h2]The test route[/h2]
Every run starts on South St in West Point on the vanilla map, so every save runs the same streets.
[list]
[*]a 60 s drive (chunk loading at driving speed)
[*]a walk loop with real Walk To pathfinding
[*]a small and a large zombie fight
[*]looting six containers in one house
[*]a drive back, and a drive along a tree-lined road
[*]a real car down the Dixie Highway at 120 km/h
[*]a fight where you swing yourself
[*]500 zombies crowding round you
[*]the first drive again in fog
[/list]

[h2]How to use it[/h2]
[olist]
[*]Make a copy of your save (copy its folder under [i]Zomboid\Saves\[/i]). [b]A run changes the save it runs in[/b]: it teleports you, spawns and removes zombies, removes parked cars on the fast-drive road, and changes time and weather. You are put back where you were at the end.
[*]Enable Test Ground in that save and load it.
[*]Right-click the ground > [b]Test Ground[/b] > [b]Run the fixed baseline (West Point)[/b]. The first time in a save it asks you to confirm.
[*]Wait for the run to end (about 15 minutes). Keep the game window in front: if the game pauses when it loses focus, the run pauses too.
[/olist]
The report is written to [i]Zomboid\Lua\TestGround_baseline_<id>.txt[/i], with a per-second CSV and a spike list next to it.

[h2]Good to know[/h2]
[list]
[*][b]Singleplayer only.[/b] It does nothing on a server.
[*][b]Vanilla map.[/b] The start and the routes are on the vanilla map. Map mods that change those streets make the fast drive and tree road fall back to shorter roads.
[*][b]Can't die mode.[/b] Outside debug mode the game doesn't allow god mode from Lua, so the fights restore your health every tick instead. Launch with -debug for real god mode.
[*]Zombies you spawn or kill and the time that passes during the run stay in the save. That's why you use a copy.
[*]Plans are plain text in [i]Zomboid\Lua\[/i]; you can write your own (see the plan file Test Ground creates on first load).
[/list]

[h2]Scripted runs and AI agents[/h2]
[b]Test Ground Bridge[/b], a separate add-on, lets scripts and AI agents drive Test Ground from outside the game and comes with a Claude skill for building test cases. It is separate because it can run code in your game; Test Ground on its own reads no command files.
