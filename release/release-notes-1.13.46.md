# Release notes text, Test Ground 1.13.46 (for the release thread, 2026-10-21)

- Benchmark Save copies your save with the new **Test Ground Save Copier** mod (needs ZombieBuddy). **Test Ground Capture no longer copies saves** (since 1.0.9): it keeps screenshots, the film and the aim point, and belongs in the Dev Add-on. Without the Save Copier, the picker says so as soon as it opens and "New vanilla save" still works.
- Each run also writes a readable Markdown report, `TestGround_<plan>_<id>.md.txt` (rename to `.md` to view it rendered; the game will not write `.md` files). It names the save but not its folders.
- `ui = hide` (showcase films) hides the clock, the speed buttons and mod clocks such as Exact Minute Clock for the run, and leaves them as they were afterwards.
